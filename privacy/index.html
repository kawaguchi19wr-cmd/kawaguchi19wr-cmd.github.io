Privacy Policy

Blure Classic Records — last updated October 14, 2026

Who we are

Blure Classic Records is an independent music label and the home of the artist Blure Rhodes. This policy covers our internal tool, "Blure API", and this website.

What Blure API does

Blure API is used only by the label to manage its own YouTube channel and Instagram account: uploading our own videos and reading performance statistics (such as views and watch time) for our own content. It is not offered to the public, and no one outside the label signs in to it.

Data we access

Through the YouTube API Services, Blure API accesses data for the label's own YouTube channel only. We do not access, collect or store personal information about viewers or other users. Aggregated statistics about our own content are stored privately for the label's analysis and are not sold or shared with third parties.

YouTube API Services

Blure API uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. See also the Google Privacy Policy. Access can be revoked at any time from the Google security settings page.

Data retention and deletion

Blure API does not store Google or YouTube account credentials in any database. The OAuth refresh token is kept only as a private environment setting of the label's own tool. Aggregated statistics about our own channel are kept for no longer than 36 months and are then deleted. To stop Blure API from accessing the channel, revoke access from the Google security settings page; we then delete the stored token and any statistics within 30 days. You can also ask us to delete data at any time by writing to blurerhodes@gmail.com.

This website

This website does not use cookies, analytics or tracking, and does not collect personal information.
