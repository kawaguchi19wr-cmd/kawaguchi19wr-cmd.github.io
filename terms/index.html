About Blure API

"Blure API" is an internal tool of Blure Classic Records. It is used only by the label to manage its own YouTube channel (Blure Rhodes) and its own Instagram account: uploading and scheduling the label's own videos, and reading performance statistics for the label's own content. It is not offered to the public, and no one outside the label signs in to it.

YouTube API Services

Blure API uses YouTube API Services. Anyone using Blure API agrees to be bound by the YouTube Terms of Service. Use of Google data is also described in the Google Privacy Policy and in our Privacy Policy.

Content

All videos uploaded with Blure API are original works owned by Blure Classic Records. Blure API does not download, copy or re-distribute content from other channels.

Revoking access

Access to the channel can be revoked at any time from the Google security settings page.
